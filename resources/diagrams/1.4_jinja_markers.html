Jinja: the three markers
Jinja runs first — the warehouse only ever sees plain SQL
you write
the warehouse gets
{{ ... }}  Expression
Outputs a value — reference variables, call functions like ref()
SELECT {{ 2 + 2 }} AS four
FROM {{ ref('job_postings') }}
SELECT 4 AS four
FROM "dev"."main"."job_postings"
{% ... %}  Statement
Logic — for loops, if, setting variables. Outputs nothing itself
you'll write these soon
{% for n in [1, 2] %}
SELECT {{ n }} AS n
{% endfor %}
SELECT 1 AS n
SELECT 2 AS n
-- the loop wrote the SQL for you

Never executes, never ships — vanishes at compile
