Anatomy of a dbt project
what uv init + dbt init scaffolded — and the lesson where each piece comes alive
🗂️  dbt_course/ your repo — root
data/ raw parquet files outside the project
dev.duckdb your local DuckDB warehouse — appears on first connection
scripts/ EL — gets data in; dbt takes over from there outside the project
job_postings/ the dbt project
dbt_project.yml  — the badge
📁 models/
your SQL — one SELECT per file, versioned
📁 seeds/
small lookup CSVs that live in the repo
📁 analyses/
scratch queries — compiled, never built
📁 macros/
reusable SQL functions — you'll write one
📁 tests/
declared checks that fail loudly on bad data
📁 snapshots/
row history as your data changes over time
🏠  ~ your home folder — not in the repo at all
.dbt/
profiles.yml
connection settings — dbt init wrote it (1.22)
