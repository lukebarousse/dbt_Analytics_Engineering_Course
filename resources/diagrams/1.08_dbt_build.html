dbt build: Three Commands in One
🚀 dbt build =
🌱
dbt seed
loads reference CSVs
+
🏗️
dbt run
builds the models
+
🛡️
dbt test
checks the data

🌱

🏗️
model
✓ built
🛡️
its test
✗ ERROR
🏗️
downstream model
⏭ SKIP
🛡️
its test
⏭ SKIP
