# resources/

Production assets for the course videos. Nothing here is needed to run
either project.

- `diagrams/`: every diagram shown in the videos, as a standalone `.html`
  file plus its exported `.png`. File names start with the lesson number
  (`1.05_how_a_source_works`). `tokens.md` holds the shared colors and fonts.
- `images/`: logos and photos used in the videos.
